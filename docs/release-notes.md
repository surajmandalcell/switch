Switch is a native macOS app for keeping multiple Codex accounts ready and
switching the account used by new sessions.

This release includes compact Menubar usage limits, saved account switching,
usage refresh, conversation history, daily activity, imports, and Cleanup.

Download the Mac ZIP, unzip it, and move `Switch.app` to Applications. Switch
requires macOS 14 or later on Apple Silicon and Codex CLI.

The release also includes the `switch-codex` npm package for terminal use.
